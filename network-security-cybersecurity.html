PERIMETER DEFENCE

Firewall Installation and Configuration

Configure supported network firewalls and security gateways to control traffic entering, leaving and moving within an organisation's network.

Depending on platform and scope, work may include interface and zone setup, firewall rules, NAT, service restrictions, administrative access controls, logging and configuration backups. Policies should be based on approved business requirements and least-privilege access.

NETWORK SEGMENTATION

VLANs and Internal Network Protection

Separate business systems and user groups into logical network segments to reduce unnecessary access between devices and services.

Segmentation may distinguish staff, guests, servers, CCTV, IP telephony, building systems and network management. Router, switch and firewall capabilities must support the design, and inter-segment traffic should be explicitly controlled and tested.

SECURE CONNECTIVITY

VPN and Remote Access Security

Configure supported site-to-site and remote-access VPN solutions for authorised branches, administrators and remote users.

Design considerations include peer compatibility, authentication, encryption, routing, endpoint requirements, access restrictions, key or credential lifecycle and secure administration. Remote management interfaces should not be unnecessarily exposed to the public internet.

INFRASTRUCTURE HARDENING

Router, Switch and Network Device Hardening

Review supported network device settings and apply security controls appropriate to the equipment and operating environment.

Work may include changing default credentials, restricting management services, using secure administration protocols, limiting management access by source, reviewing unused services and ports, applying approved updates and maintaining configuration backups.

WIRELESS PROTECTION

Wi-Fi and Guest Network Security

Improve the security of enterprise and campus wireless networks through supported encryption, authentication, access policies and separation of guest and internal traffic.

Wireless design should consider access point capabilities, client compatibility, credential management, coverage, roaming and how wireless traffic is controlled when it reaches the wired network.

SECURITY REVIEW

Network Configuration Review and Risk Reduction

Review available network diagrams, device configurations, access policies and operational practices to identify configuration weaknesses and practical improvement opportunities.

A review may cover exposed management services, broad firewall rules, shared credentials, outdated firmware, unnecessary open ports, flat networks and gaps in configuration backup. Findings depend on authorised access and the information provided.

ENDPOINT & SERVER COORDINATION

ICT Infrastructure Protection

Coordinate network controls with the organisation's endpoint, server, CCTV, access control, IP PBX and cloud-connected systems.

Where separately scoped and supported, this may include network access restrictions, segmentation, secure connectivity and coordination with endpoint protection or backup platforms. Endpoint licences, managed detection services and cloud subscriptions are not automatically included.

ONGOING SUPPORT

Security Maintenance and Configuration Support

Maintain supported network security configurations through planned reviews, configuration backups, approved firmware updates, change control and troubleshooting.

Maintenance arrangements should define covered equipment, authorised access, update windows, backup handling, escalation contacts, response times and reporting. Continuous monitoring or a staffed 24-hour security operations centre is not included unless expressly agreed.

Our Network Security Implementation Process

1. Scope and authorisation

Confirm the systems in scope, responsible contacts, authorised access, business priorities, change windows and any restrictions. Security testing or intrusive activity requires explicit written authorisation and a separately defined scope.

2. Review and security design

Review the available topology, device capabilities, current policies, remote access, wireless design and operational requirements. Document recommended changes, dependencies and rollback considerations.

3. Controlled implementation and verification

Apply approved configuration changes, verify expected connectivity and access restrictions, record relevant settings and provide a summary of implemented work and outstanding recommendations.

What to Include in a Security Enquiry

To help scope a network security review or implementation, share the following details where available:

  • Organisation type, site locations and number of users or branches.
  • Network diagram, IP addressing plan, VLAN list and internet/WAN connectivity details.
  • Router, firewall, switch and wireless equipment makes, models and software versions.
  • Current firewall rules, VPN arrangements and remote administration requirements, shared only through a secure approved channel.
  • Systems that need separation, such as staff, guests, CCTV, servers, IP phones and building systems.
  • Known network issues, suspected weaknesses, recent changes or security concerns.
  • Existing endpoint protection, backup, identity and cloud security platforms, if relevant.
  • Required maintenance window, change approval process, documentation and support expectations.

Important: Do not send passwords, private keys, recovery codes, live configuration secrets or sensitive personal information through a public enquiry form. Credentials should be exchanged only through an agreed secure process.

What network security services does Mlina provide?

Depending on the agreed scope, services may include firewall configuration, network segmentation, VPN security, secure device administration, wireless security, configuration reviews, hardening and maintenance support.

Can you configure business firewalls?

Firewall rules, NAT, management access, logging and traffic policies can be configured on supported equipment according to documented business requirements and approved access.

Can you separate CCTV, guest Wi-Fi and office networks?

VLANs and firewall policies can separate supported systems and user groups. The design must account for equipment capabilities and control traffic between segments.

Do you secure remote access and VPN connections?

Supported VPN solutions can be configured with appropriate authentication, encryption, routing and access restrictions. Remote administration should be limited to authorised users.

Do you provide 24-hour cybersecurity monitoring?

This service page describes infrastructure configuration and support, not an automatically included staffed 24-hour security operations centre or continuous incident monitoring. Such arrangements require separate assessment and agreement.

Do you perform penetration testing or compliance certification?

Penetration testing, formal audits and compliance certification are not implied by general network security configuration. Specialist engagements require a separately agreed scope, authorisation, methodology and appropriately qualified resources.

Can you improve Wi-Fi security?

Wireless security configuration may include supported encryption settings, secure administration, guest network separation and review of access controls.
